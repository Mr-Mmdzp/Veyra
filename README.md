# Veyra Estates

A modern luxury real estate showcase built with HTML, Tailwind CSS, and JavaScript.

## About

Veyra V1 was built mainly as a **showcase project** — focusing on a clean luxury UI, dynamic property rendering, search, filtering, responsive design, and interactive property inspection.

This version was never meant to be the final form of Veyra.

**Veyra V2 is going to go much harder. 😈**

More features, deeper functionality, better architecture, authentication, favorites, themes, and a much more complete real-estate experience are planned for V2.

> V1 was just the beginning. V2 is going to break it. 🔥

## Built With

- Tailwind CSS
